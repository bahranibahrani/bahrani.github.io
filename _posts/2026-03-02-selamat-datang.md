## Halo Dunia!

Ini adalah post pertama di blog catatan pribadi saya. Saya menggunakan:

- **Jekyll** - Static site generator
- **Minimal Mistakes** - Tema yang fleksibel dan keren
- **GitLab Pages** - Hosting gratis

## Mengapa Jekyll?

Jekyll sangat cocok untuk:

1. **Blog pribadi** - Mudah menulis dalam Markdown
2. **Catatan belajar** - Organisasi dengan kategori dan tag
3. **Portofolio** - Tampilan profesional
4. **Gratis hosting** - Bisa di GitLab Pages atau GitHub Pages

## Fitur Minimal Mistakes

Tema ini memiliki banyak fitur:

- Responsive design
- SEO friendly
- Dark mode support
- Search functionality
- Comment system
- Dan masih banyak lagi!
