# 🌐 Bahrani's Blog

Blog catatan pribadi untuk berbagi pengetahuan dan pengalaman tentang **Network Engineering**, **DevOps**, dan **System Administration**.

## 🚀 Live Site

👉 **[https://bahrani.my.id](https://bahrani.my.id)**

## 🛠️ Tech Stack

- **[Jekyll](https://jekyllrb.com/)** - Static site generator
- **[Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)** - Jekyll theme
- **[GitHub Pages](https://pages.github.com/)** - Hosting
- **[GitHub Actions](https://github.com/features/actions)** - CI/CD

## 📂 Struktur Proyek

```
├── _config.yml          # Konfigurasi utama
├── _posts/              # Artikel blog
├── _pages/              # Halaman statis
├── assets/
│   ├── css/             # Custom CSS
│   └── images/          # Gambar dan foto
├── Gemfile              # Ruby dependencies
└── .github/workflows/   # GitHub Actions
```

## 🏃 Menjalankan di Lokal

```bash
# Install dependencies
bundle install

# Jalankan server
bundle exec jekyll serve

# Buka di browser
# http://127.0.0.1:4000
```
